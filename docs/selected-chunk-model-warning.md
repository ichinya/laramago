The Laravel preset omits an ambiguous-method advisory on a standard hydrated chunk model when current source and native declarations identify the concrete model's public instance method. The callback must have a literal typed Collection parameter. Its first use is a by-value receiving helper whose Collection formal accepts the independently certified model domain and whose only formal read is a by-value foreach. A later foreach retains that Collection and its model receiver without rebinding, references, aliases, or escapes. The selected concrete model must physically declare a public instance zero-argument void method.

This is a bounded reporting policy. It leaves native types, callback generics, control flow, Errors, and unrelated advisories unchanged. It does not execute callbacks or infer opaque closure identifiers. Unknown dispatch, changed standard framework declarations, incompatible formals, magic or reference methods, custom collection mappings, and unproved lifetimes retain the original advisory. Source shells keep exact spans for current native caller binding while releasing the complete caller AST before metadata queries.

Construct `SelectedChunkModelWarningPlugin($projectRoot, preserveAdvisories: true)` to retain these advisories. The fixture runner checks the complete source matrix and the whole diagnostic multiset with the current production registry, preserves independent Errors, tests default-engine extension worker counts one and three, and changes actual selected SDK cache entries and source lifetimes with exact restoration. Its metadata profiles are observation and control receipts, never application-name admission lists.
