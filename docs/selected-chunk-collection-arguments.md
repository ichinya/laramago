# Selected chunk collection arguments

A literal `chunkById` callback can receive a concrete model collection even when its physical `Collection` parameter leaves the native body type at `Collection<array-key, Model>`. This adapter applies the standard declared Eloquent hydration generic to one unchanged collection argument passed to a physically bound receiving method.

The proof binds the named caller, callback and formal spans, fresh literal model query, selected query operations, framework chunk/get implementations, collection factory, standard builder and collection defaults, and the receiving parameter. The full argument diagnostic remains the trigger; its printed types do not establish the domain.

Query or collection aliases, references, reassignments, escapes, selected model configuration, custom builder/query/collection dispatch, unknown producers, stored callbacks, and stronger callback documentation retain their native Errors. Captured counters may change after the selected collection argument because those counters cannot replace that argument.

The adapter preserves native types and all unrelated diagnostics. It uses no later file hook or derived closure identifier. Fixture acceptance requires genuine native witnesses, exact complete issue preservation, actual selected SDK cache mutations and restoration, and isolated/full production registry checks with one and three host workers.
