# Model attribute source freshness

Model attribute read certificates keep the first observed source hash for every selected declaration. A known dependency must still have those exact bytes before its syntax is reread. This also covers declarations included for native metadata but absent from the analyzed source paths: evicting their AST cannot replace the earlier certificate with changed source. Analyzed declarations, explicit directional PHPDoc, generic inheritance and cast priority retain their existing checks.

Run `php -d memory_limit=512M -d opcache.enable_cli=0 tests/model-attribute-source-freshness.php`. Native analysis is the default; `--prepare-only` prepares and parses the existing neutral fixture without an analyzer. The regression requires one genuine native Error before controls and uses the same real issue context throughout. Two actual native declaration reads must evict the already certified unscanned model AST from the two-entry reader. A physical source change must defer the correction; exact byte restoration must readmit it. All thirteen checks and complete native diagnostic equality are required. Workers use 512 MiB and 120-second requests, with one analyzer thread for the source mutation controls. Fixture, application bootstrap and migration bodies are trapped against execution.

`php tests/refreshed-model-properties.php --integrated` remains the separate registered regression for read contracts and priority. It requires its existing 139 issue/metadata controls and fifty genuine native JSON controls. The freshness test does not replace those gates or claim that persistence or an application assertion succeeds.
