# Static custom Blade directives

`BladeDirectiveCatalog` reads selected `Blade::directive()` and `Blade::if()`
registrations from PHP source. It does not bootstrap Laravel, execute provider or
callback bodies, compile Blade templates, or inspect the runtime compiler registry.

Select effective registration sources in Composer metadata:

```json
{
  "extra": {
    "laramago": {
      "blade-directives": {
        "files": [
          { "file": "app/Providers/AppServiceProvider.php", "provider": "App\\Providers\\AppServiceProvider" },
          "bootstrap/directives.php"
        ],
        "complete": false
      }
    }
  }
}
```

An object selects the public zero-argument `boot()` body of a concrete class
directly extending `Illuminate\Support\ServiceProvider`; an empty `register()`
is allowed. A string selects top-level registrations. The selected bodies may
contain imports and direct calls to the native `Blade` facade only. Direct
registrations require a literal valid name and an inline closure or arrow
function. A literal `bind` argument is accepted. `Blade::if()` requires an
inline callback and contributes four names: `name`, `unlessname`, `elsename`,
and `endname`. Generated names retain distinct `if`, `unless`, `else`, and
`end` kinds. A later registration replaces an earlier entry with the same
name, including a name generated by `Blade::if()`.

The source selection asserts that each selected file or provider runs and that
they run in list order. The catalog cannot prove provider activation or package
registration order. Unsupported statements, conditions, variables in place of
handlers or names, unreadable source, and paths outside the project make the
whole snapshot unknown. `complete: true` additionally asserts that the
selected map is the entire effective custom directive registry, including
framework and package registrations. Without that assertion, missing names
remain unknown. This completeness claim does not describe built-in compiler
directives; a registered custom name takes precedence over a built-in name
when Blade compiles it.

`directives(): ?array` returns an exact-name map of
`BladeDirectiveDeclaration` objects, or null for an unknown catalog.
`get(string): ?BladeDirectiveDeclaration` looks up one name.
`contains(string): ?bool` returns false for absence only in a complete catalog.
`isComplete(): bool` reports that assertion. Each declaration records its
effective name and kind, absolute source path, original PHP name-literal byte
span (`start`, inclusive; `end`, exclusive), and whether its registered
compiler handler declares an expression parameter. For generated condition names, the
span points to the original `Blade::if()` name literal. Create a new catalog
after editing configuration or source; an instance is a source snapshot.

`declaresExpressionParameter` records a declared compiler-handler parameter, not runtime argument acceptance or a required-expression rule. A PHP closure without declared parameters may still inspect additional arguments.
