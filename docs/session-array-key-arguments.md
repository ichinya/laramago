Session key copies use the declared bare-array source and the physical Store normalization into Arr::set, whose declared key accepts integers and strings. Native array-key metadata is inspected semantically and kept unchanged. This applies the PHPStan benevolent array-key policy only to the closed key/value copy; aliases, references, rebinding, changed forwarding, nonstandard attribute storage and unrelated receiving contracts remain Errors. No application body or fixture body is executed.

The native plain string branch may carry the SDK General refinement with a null literal value, all string refinement flags false and unspecified casing. Literal, unspecified-literal, numeric, truthy, nonempty, callable and cased string branches remain outside the adapter. The runner requires every genuine positive after the native and AlwaysKeep stages before starting cache controls.
