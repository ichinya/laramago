# Blade directive references

`BladeNativeDirectiveCatalog` reads `compile*` methods from the installed
Laravel `BladeCompiler`, its base `Compiler`, and selected `Compiles*` traits. It reads source
files under Composer's configured `vendor-dir`; it does not load Laravel or
compile a view. `names()` is null when that compiler source is unavailable or
uses an unrecognized trait layout. The native list also includes `verbatim`
and `endverbatim`, which Blade handles before statement compilation.

`BladeDirectiveReferenceChecker` accepts that native list and the effective
custom map from `BladeDirectiveCatalog::directives()`. For example:

```php
$native = (new BladeNativeDirectiveCatalog($projectRoot))->names();
$custom = new BladeDirectiveCatalog($projectRoot);
$checker = new BladeDirectiveReferenceChecker(
    $native,
    $custom->directives(),
    $custom->isComplete() && $effectiveRegistryIsComplete,
);
$references = $checker->check($bladeSource);
```

`$effectiveRegistryIsComplete` is an explicit project assertion that no
unselected registration, conditional registration, compiler extension,
precompiler, or compiler subclass changes the effective directive set. A
complete custom catalog alone does not prove this. The checker recognizes
custom names exactly as registered, including the four names generated by
`Blade::if()`, and recognizes native compiler methods without case sensitivity.
Custom registrations may override native names; the reference remains known.

Each result contains `name`, `status` (`known`, `missing`, or `unknown`) and
original Blade byte offsets `[start, end)`, including `@`. Only `missing` is a
proven absent name. An unavailable native or custom catalog, or an incomplete
effective assertion, changes absent names to `unknown`. The scanner returns
null for oversized or ambiguous source, including unclosed opaque regions.
It skips escaped `@@`, Blade and HTML comments, verbatim and raw PHP blocks,
PHP tokens, Blade echo regions, and component tag markup precompiled by Blade.
If Blade's raw PHP regex reaches a terminator inside a PHP string or comment,
the checker defers the whole source instead of treating the trailing text as
independent directives.
Directive arguments are treated as a
single expression so a string inside one cannot become another reference.

The checker is metadata for a Blade source consumer. It does not emit PHP
warnings, run the compiler, verify directive arguments, or promise that a
template renders successfully. Native method discovery is deliberately broad:
an internal `compile*` method may appear as a known name, so a known result
only means that missing-name proof is unavailable for that name.
