Ordinary branches, other cardinalities, rebound receivers, writes, references, arbitrary calls and side effects defer.

This is an intentional defensive reporting policy. It does not prove XML cardinality, execute XML or application code, change native types or control flow, remove Errors, or alter unrelated warnings. `new XmlCardinalityGuardPlugin($root, preserveAdvisories: true)` keeps the advisory when the plugin is constructed directly.

The certificate binds the current physical caller and the genuine built-in loader, SimpleXMLElement, exception, count and array predicate metadata. Three complete measured built-in declaration profiles are exact reference contracts. A different or stronger API, a user-defined replacement, incomplete metadata, stale bytes or namespace override defers. No application-specific class or source hash is used as a compatibility allowance.
