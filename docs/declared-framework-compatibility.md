Direct `??` reads from the declared Eloquent `Model` contract can retain PHPStan's advisory behavior when the current source, native magic methods and `ArrayAccess` role agree. The rule removes only the exact ambiguous-property Warning for that read. Known physical or documented properties, writes, different receivers and unrelated diagnostics remain visible.

Collection offsets with a nullable integer or string key use PHP's native array key coercion when the current collection hierarchy exposes the verified array storage and ordinary read, existence and setter contracts. A source-bound local scalar accumulator passed to `reduce` may borrow its own fresh seed by reference without borrowing item storage. The rule proves neither key presence nor the returned value's nullability, and preserves custom storage, aliases, unsafe effects and other issue envelopes.

Guarded console inputs reuse `ConsoleOptionProvider::readLiteralIssue` to apply the existing literal command declaration contract without constructing an invocation or changing the receiving parameter. Zero-argument `Request::route()` follows the source-bound Laravel/Larastan `Route|null` contract; repeated guarded calls use the existing PHPStan remembrance policy. A backed property with only a verified setter remains readable through its native declared type. These proofs retain the original native DTOs and reject unguarded uses, rebindings, getter hooks, unknown input declarations and mismatched source metadata.

The standalone public tests `coalesce-model-properties.php`, `nullable-collection-offsets.php` and `framework-null-flow.php` run actual native, Always-Keep, isolated and full registry comparisons with one and three host workers. Cache mutations run with one engine thread; the other jobs use the default engine. They preserve complete unrelated issues and source hashes, retain closed failure receipts, use 512 MiB workers and a 120-second request deadline, and never execute fixture or application bodies.
